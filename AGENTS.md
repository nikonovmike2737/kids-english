# Kids English — router для ChatGPT и Codex

Публичный проект без персональных данных. GitHub — единственный источник утверждённых материалов и кода.

## Ветки и роли
- `main`: утверждённый контент и опубликованная версия сайта.
- `canon/source-of-truth`: работа над каноническими правилами, проверка и PR в `main`.
- `role/methodologist`: создание и приёмка программы, учебных материалов и работы с отзывами взрослых.
- `role/technical`: сайт, тесты, публикация и техническая приёмка.

## Обязательное чтение
1. `docs/source-of-truth/PROJECT_CHARTER.md`
2. `docs/source-of-truth/ROLE_METHODOLOGIST.md` или `ROLE_TECHNICAL.md`
3. `docs/source-of-truth/CONTENT_AND_PRIVACY_CANON.md`
4. `docs/source-of-truth/WORKFLOW.md`
5. `docs/source-of-truth/SOURCE_INVENTORY.md`
6. `docs/source-of-truth/GAMEPLAY_CANON.md`
7. `docs/methodology/QUESTION_DESIGN.md`

## Инварианты
- Название продукта: Kids English. Никаких имён ребёнка, семьи или других персональных данных.
- Статический публичный сайт. Проверка, сборка фраз, сопоставление и отчёт по каждому заданию происходят в браузере.
- Не собирать данные с сайта: нет формы обратной связи, аналитики, сервера, cookies или сохранения результатов.
- Результат текущего прохождения существует только в памяти страницы и сбрасывается при повторном запуске.
- Отзывы взрослых поступают только в чат ChatGPT/Codex, фиксируются обезличенно с lesson_id/task_id и превращаются в изменение через PR.
- Все восстановленные из контекста материалы помечать RECONSTRUCTED до сверки с оригиналами, подтверждённые — VERIFIED.
- Изменения канонов, контента и кода публиковать через ветки и PR в main, если не требуется первоначальная инициализация.
- Не объявлять страницу опубликованной без проверки рабочего публичного URL.

- Игровой инвариант всех текущих/будущих карточек: 3 сердца на весь урок; неверный ответ только минус 1 жизнь без подсказок; новый Check разрешён; переход после верного ответа; zero lives → грустный кот 😿 + restart.
