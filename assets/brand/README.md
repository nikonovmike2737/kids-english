# Kids English brand sources

Approved visual identity, 2026-11-23. Both assets are stored as stand-alone PNG files in this public repository, not inline in HTML.

- `abc-cat-logo.png` — cheerful orange kitten above white ABC on purple rounded-square. **96 × 96 PNG**, used as the favicon and the site header logo (optimized web variant of the approved artwork).
- `cat-mascot.png` — seated orange plush kitten on transparent background. **240 × 240 PNG**, used in the homepage hero in place of the teddy-bear emoji (optimized web variant).

The high-resolution generated masters are retained as conversation artifacts; these standalone optimized PNG assets are the canonical files used by the production site. No personal data or remote image-hosting dependencies.
