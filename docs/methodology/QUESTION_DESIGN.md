# Канон разработки упражнений и методической приёмки
Статус: DRAFT_CANON начального цикла; основан на восстановленных материалах.

Каждое задание: task_id (например ENG-001-Q01), lesson_id, цель, текст, ожидаемый ответ, wrong-answer explanatory feedback, тип, provenance, версия.
Типы:
- choice — один однозначный правильный ответ среди 2–4;
- match — пары слово/эмодзи или картинка, без неоднозначных символов;
- order — составить фразу последовательным нажатием слов; не требовать drag-and-drop;
- later: звук/движение/сортировка при наличии проверяемой логики.
Браузер сам проверяет ответ, сразу объясняет правильную форму и показывает итог по каждому вопросу. Временно хранить результат только в RAM вкладки, без сетевых запросов/внешней записи.

Проверки методолога:
1. Возрастная понятность и отсутствие недетерминированных правильных вариантов.
2. Естественные английские формулировки и корректный перевод.
3. Связь с целями урока; один навык или осознанная интеграция навыков.
4. Полезное объяснение неверного ответа, без наказаний.
5. Повторяемость с равным результатом при равном ответе.
6. Ключ «He is / She is / It is» и «I'm + adjective» проверять отдельно от «I + verb».
7. Нельзя выдавать RECONSTRUCTED материал за подтверждённый оригинал.
