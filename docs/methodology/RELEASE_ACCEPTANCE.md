# Kids English — приемка уроков и интерактивных карточек
Статус: CANONICAL · 2026-11-23.
Обязательное чтение: `docs/methodology/QUESTION_DESIGN.md`, `docs/source-of-truth/GAMEPLAY_CANON.md`.

## METHOD_PASS
- Формулировки, переводы, визуальный стимул и ключ правильного ответа корректны, однозначны и подходят 5–7 годам.
- Ни одно заглавное изображение не копирует правильный вариант ответа; нет спойлеров ни в title/caption/figure, ни в цветах/порядке вариантов; отдельно ENG-002 «Swim».
- Ошибочная проверка говорит только «Неправильно»; не раскрывает правильный вариант, неверную пару или порядок слов.
- Сопоставление оценивается только целиком по кнопке «Проверить»; частичного подтверждения правильности нет.
- Движение к следующей карточке происходит **только после правильного ответа**, в том числе после нескольких попыток.
- Упражнения связаны с целью урока; provenance VERIFIED/RECONSTRUCTED указан; публичный контент обезличен.

## TECH_PASS
- ENG-001/002/003 доступны с главной; 4 карточки на каждый урок; choice/match/order работают.
- На старте 3 сердца на **весь** урок; на неверный Check теряется ровно 1; верный Check не тратит сердце.
- Все карточки содержат кнопку «Проверить»; «Далее» скрыта до правильного ответа; неверный ответ допускает новую попытку в этой же карточке.
- После последнего сердца — грустный кот 😿 + модальный экран и кнопка нового прохождения; прогресс/жизни сбрасываются.
- При неверном ответе нет подсказки ни в тексте, ни в подсвеченном варианте, ни в мгновенной проверке отдельных пар.
- В конце успешного прохождения результат по каждой карточке и остаток сердец. Нет сохранения/передачи персональных результатов.
- Проверены успех 12/12; неправильный choice, match, order → повторная попытка; 3 ошибки → modal; повторный запуск; узкие экраны; отсутствие JS exceptions и отправки данных.
- GitHub Actions успешно опубликовал `main`; **внешняя** проверка публичного URL подтверждает версию.
Без подтверждения соответствующих пунктов статус: NOT_VERIFIED.

## G10 — обязательный gate перемешивания (2026-11-24)
- METHOD: все карточки соответствуют QUESTION_DESIGN §F; не менее трёх однозначных match-пар, четыре choice-варианта, минимум три токена order (для двухсловного ответа — знакомый лишний токен).
- TECH: при полном повторе после провала, успеха или выхода прежний позиционный ответ не работает для каждого типа; обе match-колонки и их соответствие изменены. Проверить последнюю реально увиденную раскладку после промежуточной незавершённой попытки. Выбор, отмена, ошибка внутри карточки не меняют раскладку. Все 12 карточек, Chromium/WebKit, mobile, Classic, жизни, ключи, отсутствие хранения/отправки ответов. CI и hosted QA обязательны.
