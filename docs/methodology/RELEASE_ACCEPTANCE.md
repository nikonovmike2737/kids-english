# Контрольный список приемки
METHOD_PASS:
- учебные цели и задания соответствуют возрасту 5–7 и плану;
- все словоформы/фразы/переводы проверены;
- правильные ответы однозначны, обратная связь педагогически корректна;
- есть игровая практика и короткая самостоятельная проверка;
- публичный контент обезличен;
- источник помечен VERIFIED/RECONSTRUCTED.

TECH_PASS:
- ENG-001, ENG-002, ENG-003 доступны из главной;
- 4 задания в каждом (3×4=12); choice, match, order;
- проверка верного и неверного ответа и объяснение;
- результат по каждому заданию + итог;
- бесконечные рестарты;
- кнопки для сенсорных и клавиатурных устройств;
- отсутствие запросов, сбора данных, cookies/localStorage;
- commit в main и доступность сайта GitHub Pages внешним запросом.

Не подменять PASS отсутствующими проверками. В спорных случаях — NOT_VERIFIED.
