# Канон публичного контента и приватности
Статус: CANONICAL.

- Kids English — обезличенный публичный сайт. Никаких имён/фамилий детей, семейных данных, персональных профилей, точного возраста конкретного ученика, контактов, индивидуальной истории прохождений.
- Учебные материалы и сценарии можно публиковать. Взрослая обратная связь из чата — только как обезличенный продуктовый вывод, с lesson_id/task_id и категорией: engaging, too_easy, too_hard, grammar, fatigue, navigation, bug.
- Публичный GitHub видим всем и сохраняет историю. Нельзя сначала закоммитить личный текст, а потом просто удалить его из последнего файла: история останется.
- Сайт **не собирает** результаты и feedback, не отправляет запросы, не хранит cookie или localStorage, не требует входа. Внутренний временный state текущего прохождения допустим.
- Методическая активность может включать взрослого, но публичный контент не должен быть привязан к одной конкретной семье.
- Статусы источников: VERIFIED (сверен с оригиналом), RECONSTRUCTED (по контексту), DRAFT (новый неутверждённый), ACCEPTED (прошёл методологическую проверку). Статус происхождения и статус приемки независимы.
- В интерфейсе никаких форм обратной связи и ссылок «отправить результаты». Взрослые взаимодействуют в отдельном ChatGPT/Codex-чате.
- Код проверяется на наличие секретов, токенов, личных текстов и сторонней телеметрии до публикации.
