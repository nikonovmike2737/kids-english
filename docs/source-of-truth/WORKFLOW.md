# Канон работы веток и ролей
Статус: CANONICAL.

## Branch / PR
1. main — официальная актуальная версия сайта, уроков и канонов.
2. canon/source-of-truth — подготовка канонических правил, ревью обеими ролями, PR в main.
3. role/methodologist — авторинг, проверка, обратная связь, METHOD_PASS и PR в main.
4. role/technical — реализация, тесты, TECH_PASS и PR в main.
5. Публикация сайта происходит только из main. Рабочие ветки нельзя напрямую публиковать как публичную окончательную версию.

## Единица изменения
Один осмысленный PR: затронутые lesson_id/task_id, источник изменения, что поменялось, validation checklist, вердикт обеих ролей. Не смешивать unrelated изменения.

## Конвейер
Запрос → method draft → METHOD_PASS → implementation → TECH_PASS → review and PR → merge main → deploy Pages → verify URL.
Принятый коммит и сайт — разные факты, каждый проверяется отдельно.

## Обратная связь
Только взрослый текст в ChatGPT/Codex → обезличенная запись в docs/methodology/PRODUCT_FEEDBACK.md → решение методолога → задача техпартнёру при необходимости → PR → обновлённый урок/сайт.
Никакого автоматического импорта персональных сообщений в публичный репозиторий.

## Инициализация 2026-11-23
Начальные файлы размещены напрямую в main для запуска репозитория. Далее изменения делать через ветки и PR.
