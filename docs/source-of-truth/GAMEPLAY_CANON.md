# GAMEPLAY_CANON — Kids English, публичный браузерный тренажёр
Статус: CANONICAL · 2026-11-23 · авторитет: утверждённое требование владельца.
Владельцы: METHOD (содержательная семантика) + TECH (точность UI/state).
Связано: `docs/methodology/QUESTION_DESIGN.md` и `docs/methodology/RELEASE_ACCEPTANCE.md`.

## Машина состояния одного прохождения
`lesson_id`; `task_index`; `lives ∈ {3,2,1,0}`; `answers/results`; `taskMistakes`; `verified`; `page='practice'|'results'|'gameover'`.
`startLesson()`: hearts=3; task_index=0; results=[]; taskMistakes=0; verified=false.
`changeSelection()`: состояние ответа меняется, жизни не меняются; `next` скрыт.
`check(correct=true)`: `verified=true`; сохранить число ошибок карточки; не списывать жизнь; краткое «Правильно»; показать `next`.
`check(correct=false)`: `lives -= 1` **ровно один раз за нажатие «Проверить»**; `taskMistakes++`; «Неправильно» без ключа или направления ответа; оставить редактирование того же вопроса.
`lives == 0`: открыть полноэкранный доступный `role=dialog aria-modal=true` с грустным котом и явной кнопкой рестарта; запретить дальнейший переход.
`next()`: доступно только после `verified=true` и `lives>0`. На последнем вопросе — только после успеха показать результаты; иначе следующий вопрос без восстановления жизней.
`restart()`: полностью сбросить прогресс и восстановить ровно 3 сердца без лимита повторений.

## Виды карточек
1. **choice**: выбор, затем явная кнопка `Проверить`. Ошибка — ни выделения правильного ответа, ни текста-ключа; сброс выделения для новой попытки.
2. **match**: пользователь сопоставляет все пары; нейтральные номера обозначают только сделанные связи. Кнопка `Проверить` активна, когда сопоставлены все пары. Отдельные пары до общей проверки не оценивать. Ошибка всего набора = минус 1 сердце; очистить связи для повторного решения без раскрытия ошибочных пар.
3. **order**: собрать все слова, затем `Проверить`; ошибка = минус 1 сердце, обнулить порядок слов для новой сборки; никогда не показывать правильную последовательность.

## UI-инварианты
- Три видимых сердца на всех экранах задания; статус доступен экранному диктору.
- Кнопки «Далее» нет до правильного ответа и после неправильно проверенного ответа. Последний экран использует «Показать результат».
- Ошибочный ответ — только бинарное сообщение о неверности, никаких подсказок.
- На главной, в шапке и модальном окне можно использовать существующий кото-бренд; для `gameover` использовать грустного котика 😿.
- Никаких сетевых отправок ответов, аналитики, cookies или идентифицируемых результатов. После утверждения Adventure Island локальное сохранение обезличенных **достижений** в `localStorage` разрешено отдельным каноном; это не сохранение ответов.
- Состояние **текущей попытки** (ответы, жизни, ошибки, индекс карточки) хранится только в RAM вкладки и сбрасывается при новой попытке; постоянные ключи, сундуки, монеты и инвентарь хранятся локально по `ADVENTURE_ISLAND_APPROVED_CANON.md`.

## Обязательная регрессия перед prod
Для каждого текущего урока (ENG-001, ENG-002, ENG-003): все 4 вопроса пройти успешно; один неправильный и затем верный ответ для каждого типа; три неверных ответа подряд → 0 жизней и modal; перезапуск → 3 жизни и первое задание; правильный выбор не списывает жизнь; сверить отсутствие вопроса-спойлера, включая ENG-002 Swim; нет JS exceptions или исходящих POST. Обязательно проверить мобильную ширину.
